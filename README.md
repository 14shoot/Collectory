# 概要
このアプリは、カプセルトイやシールなどのコレクションアイテムを所有するユーザー同士が、交換募集や情報共有を行えるコミュニティアプリです。<br>
欲しいアイテムや譲渡可能なアイテムを登録し、ユーザー同士で交流できます。また、販売店舗などの情報を共有し、コレクター同士のつながりを支援します。

## サイトテーマ
「コレクター同士が「交換」と「情報共有」を通じてつながるコミュニティサービス」

## テーマを選んだ理由
今流行りのカプセルトイやシールは人気商品の転売が横行しており、本当に欲しい人に適切な価格でものが手に入らない状況に違和感を感じました。またカプセルトイだとほしい商品が手に入らない場合交換相手を探したいと感じることがありました。SNSでは交換募集や設置場所の情報が分散しており、情報収集に時間がかかるという課題があります。<br>
そこで、コレクターが交換募集と設置場所の情報共有を一つのサービス上で行えるアプリを作りたいと考え、このテーマを選びました。

## 【きっかけ】
自分自身が子どもからほしいと言われたものが売っておらず、手に入れるとしたら転売の商品を買うしかないことに問題点を感じました。同じ商品が欲しいもの同士が役立つ情報を気軽に交換でき、またそれぞれが欲しいものを交換できる場を作りたいと思ったのがきっかけです。

## 【問題点】
・販売情報がさまざまなSNSや公式サイトに分散しており、検索しづらい<br>
・交換希望の探し相手を見つけるのが難しい

## 【解決策】
・コレクションに特化した投稿・交換システムを提供し、場所や情報を一括して共有可能に<br>
・投稿に基づくおすすめ商品や人気商品のランキング表示<br>
・カテゴリ別検索機能により、商品や場所に合わせて情報を簡単に検索<br>
・安心して取引ができるよう評価機能の設定

# ターゲットユーザー
・子供やその親世代20〜40代<br>
・コレクションをしている人<br>
・自分のコレクション記録を簡単に残したい人

# 主な利用シーン
・購入前：欲しい商品や販売情報を探す<br>
・購入後：自分のコレクションを投稿する、他のユーザーの交換情報を探したり投稿する
