# Collectory

# 概要
このアプリは、カプセルトやシールなどのコレクションアイテムを所有するユーザー同士が、交換募集や情報共有を行えるコミュニティアプリです。
欲しいアイテムや譲渡可能なアイテムを登録し、ユーザー同士で交流できます。また、販売店舗などの情報を共有し、コレクター同士のつながりを支援します。

## サイトテーマ
「コレクター同士が「交換」と「情報共有」を通じてつながるコミュニティサービス」

## テーマを選んだ理由
子供の間でカプセルトイやシールなどが流行っているが、品薄な状況で欲しいものが手に入らず転売でしか買えず、またカプセルトイだとほしい商品が手に入らない場合交換相手を探すのが難しいと感じることがありました。また、SNSでは交換募集や設置場所の情報が分散しており、情報収集に時間がかかるという課題があります。
そこで、コレクターが交換募集と設置場所の情報共有を一つのサービス上で行えるアプリを作りたいと考え、このテーマを選びました。

## 【きっかけ】
自分自身が子供からほしいと言われたものが売っておらず、手に入れるとしたら転売の商品を買うしかないことに問題点を感じました。同じ商品が欲しいもの同士が役立つ情報を気軽に交換でき、またそれぞれが欲しいものを交換できる場を作りたいと思ったのがきっかけです。

## 【問題点】
・販売情報や交換希望の情報がさまざまなSNSや公式サイトに分散しており、検索しづらい
・同じ趣味やに行った人のリアルな感想や評価が探しにくい

## 【解決策】
・コレクションに特化した投稿・交換システムを提供し、場所、情報を一括して共有可能に
・投稿に基づくおすすめ商品や人気商品のランキング表示
・カテゴリ別検索機能により、商品や場所に合わせて情報を簡単に検索
・安心して取引ができるよう評価機能の設定

# ターゲットユーザー
・小さい子供の親世代20〜40代
・コレクションをしている人
・自分のコレクション記録を簡単に残したい人

# 主な利用シーン
・購入前：欲しい商品や販売情報を探す
・購入後：自分のコレクションを投稿する、他のユーザーの交換情報を探したり投稿する
